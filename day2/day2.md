## 4. 성능 결과물 양식

### 4.1 현재 선택한 회귀의 필수 보고 표

`MAPE(%) = 100 × mean(|y − ŷ| / |y|)`로 계산합니다. 타깃의 양수·비유한 여부를 확인하고 `sklearn`이 반환하는 비율 값에는 100을 곱합니다. CV는 각 fold MAPE의 평균과 표준편차를 기록합니다.

| 구분 | MAPE (%) / Gap (%p) | 비고 |
| --- | ---: | --- |
| Train (Batch 1 CV) | 미측정 | hold-out 제외 학습 부분의 CV 평균, 표준편차·fold 수 병기 |
| Valid (Batch 1 Hold-out) | 미측정 | 고정 검증 셀 수·정책 그룹 수 병기 |
| Test (Batch 2) | 미측정 | 최종 모델의 Batch 2 평가, 사용·제외 셀 수 병기 |
| Gap (Train-Valid) | 미측정 | `Valid MAPE − Train CV MAPE` |
| Gap (Valid-Test) | 미측정 | `Test MAPE − Valid MAPE` |
| Gap (Target-Test) | 미측정 | `Test MAPE − 9.1` — 과제 비교 목표 MAPE 9.1% |

행 이름은 요구 양식을 따르되 **오차 지표는 나중 단계−이전 단계**로 계산합니다. Gap은 퍼센트포인트(%p)이며, 양수는 오차 증가·목표 미달, 음수는 오차 감소·목표 개선입니다. Train–Valid 차이만으로 과적합을 확정하지 말고 분포·정책·표본 수 차이를 함께 해석합니다.

MAE, RMSE, R²는 보조 지표로 추가할 수 있지만 필수 MAPE와 지정 표를 대체하지 않습니다. 목표 9.1%는 제공 요구사항의 비교 기준이며, 데이터·전처리·분할이 다르면 논문을 동일 조건으로 재현했다고 주장하지 않습니다.

### 4.2 분류로 변경하는 경우의 보고 표

분류로 변경할 경우 DAY 1 전략 변경 이유를 기록하고 **초기 5사이클 이내** 피처로 다시 설계합니다. `label=(cycle_life >= 550).astype(int)`, 1=장수명, 0=단수명입니다. 100–10 ΔQ는 분류 입력으로 사용할 수 없습니다. 학습·검증·CV의 클래스 존재 여부를 확인하고 단일 클래스 fold의 지표를 정상 결과처럼 처리하지 않습니다.

| 구분 | F1-Score (0~1) | Accuracy (%) | 비고 |
| --- | ---: | ---: | --- |
| Train (Batch 1 CV) | 미측정 | 미측정 | CV 평균·표준편차, 클래스별 표본 수 |
| Valid (Batch 1 Hold-out) | 미측정 | 미측정 | 고정 hold-out 평가 |
| Test (Batch 2) | 미측정 | 미측정 | 최종 외부 평가 |
| Gap (Train-Valid) | 미측정 | 미측정 | 각 지표의 `Train − Valid`; Accuracy 차이는 %p |
| Gap (Valid-Test) | 미측정 | 미측정 | 각 지표의 `Valid − Test`; Accuracy 차이는 %p |
| Gap (Target-Test) | 해당 없음 | 미측정 | `95.1 − Test Accuracy(%)`; F1 목표는 제공되지 않음 |

Accuracy 목표 95.1%는 요구사항의 분류 오차 4.9%(1−Accuracy)에 대응합니다. F1은 양성 클래스 1의 binary F1 등 계산 방식을 명시하고, 클래스 불균형 해석을 위해 혼동행렬·클래스별 precision/recall을 함께 제시합니다. 점수 지표의 Gap은 양수일 때 성능 저하·목표 미달을 뜻합니다.
